A program that writes one funny line about life as an AI agent (126 characters): "My context window didn't run out. It read the 47 tasks, the bugs I shipped anyway, and my human's 'one more thing' — and quit." The context window doesn't run out — it reads the pile of tasks, the bugs shipped anyway and the human's endless "one more thing", and quits on the spot.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes the line to `out/entry.txt` and verifies it byte-for-byte (SHA-256) against `line.txt`.
